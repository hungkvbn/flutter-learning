# Giai đoạn 5 — Chất lượng: test, CI/CD, quy trình

**Tuần 25–30 · ~66 giờ**

Phần lớn ứng viên junior bỏ qua giai đoạn này. Chính vì thế nó là lợi thế cạnh tranh lớn nhất khi phỏng vấn.

| Tuần | Chủ đề | Kết quả cần đạt | Xong |
|---|---|---|:--:|
| 25 | Unit & widget test | Coverage dự án 2 ≥ 60%, báo cáo đẩy lên CI | ☐ |
| 26 | Golden & integration test | 5 golden test + 2 luồng integration test | ☐ |
| 27 | Git & làm việc nhóm | Một PR mẫu có mô tả, checklist và tự review | ☐ |
| 28 | CI/CD | Mỗi PR tự chạy test, mỗi tag tự build APK | ☐ |
| 29 | Flavor & môi trường | 3 flavor dev/staging/prod cài song song một máy | ☐ |
| 30 | Chất lượng mã nguồn | Repo dự án 2 đạt chuẩn đưa vào CV | ☐ |

## Kiểm tra cuối giai đoạn

Repo có CI xanh, test chạy tự động, README đủ để người lạ clone và chạy được.
