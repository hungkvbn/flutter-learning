# Ghi chú theo tuần

Cuối mỗi tuần, copy `_template.md` thành `week-XX.md` và điền:

```bash
cp notes/_template.md notes/week-02.md
```

**Viết bằng lời của mình.** Copy tài liệu vào đây là vô nghĩa — mục đích của thư mục này là ép diễn đạt lại kiến thức, đúng cái kỹ năng sẽ cần ở tuần 44–47 khi ngồi trước người phỏng vấn.

Mục **"Chưa hiểu"** là mục quan trọng nhất. Đầu tuần sau, mở lại và trả lời cho bằng được.
